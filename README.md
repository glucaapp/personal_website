# gianlucapagliaro.com

Sanitized, production-ready version of Gianluca Pagliaro’s academic website configured for the future custom domain `gianlucapagliaro.com`.

The research-focused homepage is `index.html`; personal interests are presented on `out-of-office.html`.

## Deployment

This branch can be deployed at the domain root using Cloudflare Pages or GitHub Pages with a custom domain. For Cloudflare Pages, use no framework preset, `exit 0` as the build command if one is required, and `.` as the output directory.

## Privacy

Published photographs have been resized for the web and stripped of EXIF/GPS metadata. The public CV does not contain a telephone number.
